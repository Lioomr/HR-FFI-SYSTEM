# فيديو تسويقي عربي — نظام FFI للموارد البشرية

فيديو 1080p / 30fps، مدته ~3 دقائق، مبني من **لقطات حقيقية لواجهة النظام بالعربية** (بيانات تجريبية)
مع رسوم متحركة وترجمة عربية مكتوبة، وتعليق صوتي عربي.

## الملفات
- `out/FFI-HR-marketing-video-ar-silent-small.mp4` — نسخة جاهزة بترجمة عربية مدمجة (بدون صوت، 18MB). النسخة الأعلى جودة (41MB) تُنتَج محليًا بـ `./build.sh` ولا تُرفع إلى git.
- `narration.md` — نص التعليق الصوتي (17 مشهدًا).
- `audio_urls.json` — روابط ملفات التعليق الصوتي المولّدة (17 ملفًا).
- `src/` — الفيديو نفسه (HTML + JS، خط Cairo، لقطات الشاشة في `src/img`).
- `build.sh` — يبني الفيديو كاملًا.

## إضافة التعليق الصوتي (خطوة واحدة)
يحتاج الجهاز إلى وصول لـ `d8j0ntlcm91z4.cloudfront.net` (لتنزيل ملفات الصوت) + `ffmpeg` + Node + Chromium:

```bash
cd marketing-video
CHROME_PATH=/path/to/chrome ./build.sh
```
السكربت ينزّل الصوت، يقيس مدة كل مقطع، يضبط زمن كل مشهد على الصوت الحقيقي، يعيد التصيير،
ويخرج `out/FFI-HR-marketing-video-ar.mp4`. بدون الصوت يُنتج النسخة الصامتة.

## ملاحظات
- كل الأرقام والأسماء في اللقطات **بيانات تجريبية** (الشريط العلوي يوضح ذلك).
- مشهد تطبيق الجوال **تصوّر توضيحي** مبني على تصميم الخطة (`plans/Employee Mobile App Master Plan.md`) وليس لقطة من التطبيق.
- لتغيير النص: عدّل `NARR` في `src/main.js` ثم أعد توليد الصوت.
