# Expo SDK baseline

This working tree uses the validated Expo SDK 57 baseline. Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before changing mobile dependencies, EAS configuration, or native build behavior.

The prior SDK 54 Expo Go smoke-test pin was removed on 2026-07-24. Its audit record and restoration evidence are retained in `SDK_VERSION_NOTICE.md`. Do not downgrade to SDK 54 for feature, EAS, native-acceptance, or Gate 3 work.
